## Rules for agents

- The story comes first; don't force props in.
- Fairness between the two children is absolute (see `01-brief.md`).
- Don't design puzzles that depend on unverified details (page numbers, serial numbers, kit functions, chess inventory). Check `07-open-questions.md`.
- Never damage, write on or stick to the real banknotes.
- Don't suggest new purchases unless genuinely necessary.
- When a decision is made, update the relevant file. Don't append contradicting notes.
